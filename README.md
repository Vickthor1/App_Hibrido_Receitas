<h1>Receita Fácil<h1/>
Aplicativo mobile desenvolvido com React Native + TypeScript para pesquisa e visualização de receitas utilizando uma API externa.

O objetivo do projeto é permitir que o usuário encontre receitas, visualize seus ingredientes e modo de preparo e salve suas receitas favoritas.

📱 Funcionalidades<br>
🔎 Pesquisar receitas por nome ou ingrediente<br>
🍽️ Visualizar receitas disponíveis<br>
📖 Visualizar detalhes de uma receita<br>
🥕 Listar ingredientes e quantidades<br>
👨‍🍳 Visualizar modo de preparo<br>
🏷️ Filtrar receitas por categoria<br>
❤️ Adicionar e remover receitas dos favoritos<br>
💾 Persistir favoritos localmente<br>
⏳ Exibir estados de carregamento<br>
⚠️ Tratar erros de comunicação com a API<br>
<br>
